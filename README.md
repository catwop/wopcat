# Двухботовый магазин: основной бот + админ-панель (оплата LTC)

## Структура
- main_bot.py   — бот для клиентов (каталог, оплата на LTC-кошелёк, /orders)
- admin_bot.py  — твой личный бот-админка (товары, кошелёк, подтверждение оплат, статистика)
- db.py         — общая база SQLite
- config.py     — токены и настройки

## Логика оплаты
1. Клиент жмёт "Купить" → бот показывает твой LTC-адрес
2. Клиент отправляет TXID или скриншот
3. Тебе в админ-бот приходит заявка с кнопками ✅/❌
4. Подтверждаешь → клиент получает уведомление

## Запуск
pip install aiogram aiosqlite
(дальше см. пошаговую инструкцию в переписке)
